ПРОГРАММА ДЛЯ РАСЧЕТА КИНЕМАТИКИ КШМ 
Версия 1.1 
 
================================= 
КАК ИСПОЛЬЗОВАТЬ: 
================================= 
1. Запустите run.bat или сразу Kinematic_Engine_Design_v1.101.exe
2. Следуйте инструкциям в программе (run.bat) или в help 
3. Результаты сохранятся в папку Kinematic_results 
 
================================ 
ПОДДЕРЖИВАЕМЫЕ ТИПЫ КШМ: 
================================ 
1. Аксиальный КШМ 
2. Дезаксиальный КШМ 
3. V-образный с рядом сидящими шатунами 
4. V-образный с прицепным шатуном 
 
================================ 
ФАЙЛЫ И ПАПКИ: 
================================ 
Программа автоматически создает: 
- Kinematic_params/   для входных параметров 
- Kinematic_results/  для результатов расчетов 
 
================================ 
СИСТЕМНЫЕ ТРЕБОВАНИЯ: 
================================ 
- Windows 10 или новее 
- Не требует установки дополнительных библиотек 
- Автономный исполняемый файл
